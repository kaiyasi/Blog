# GIVEN character assets

The homepage loads one Mafuyu/Ritsuka pair for the active local-time scene:

- Weekday, 06:00-17:59: `mafuyu-campus.png`, `ritsuka-campus.png`
- Weekday, 18:00-05:59: `mafuyu-stage.png`, `ritsuka-stage.png`
- Saturday and Sunday: `mafuyu-weekend.png`, `ritsuka-weekend.png`

Generate each file as a separate, full-body, high-fidelity chibi fan-art PNG with
matching proportions and complementary poses. Final files must have an alpha
channel, transparent corners, crisp edges, no text, no watermark, and no brand
logos. The layout intentionally does not substitute manga panels, official
artwork, or placeholder characters when these assets are absent.
